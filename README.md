# 🚀 Clon Super Mario Bros

es un clon de el famoso juego arcade Super Mario Bros en el que solo se busca mostrar las habilidades que tengo hasta ahora en la programacion y no fue realizado con fines de lucro . El juego puede ser jugado tanto en movil (touch) como en un ordenador (con teclados) , cuenta con el nivel 1 de el primer mundo completo.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5 (Canvas), CSS , Javascript

## ✨ Características Principales

- Deteccion De Colisiones Con Enemigos, Bloques, Super Poder.
- Funciona La Tuberia Como Medio Para Bajar en Ella Y recolectar todas Las monedas de el subterraneo.
- Al Comerse el Champiñon Para Crecer Se Podran Romper Los Ladrillos.
- Todos Los Super Poderes Funcionan
